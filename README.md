# MyFirstMod · 人物附加与生活质量提升

面向 **Degrees of Lewdity 0.5.10.12 Lyra 汉化版** 的 SugarCube/Twee 模组，基于 [TweeReplacer](https://github.com/.../TweeReplacer) 注入实现，无需改动本体 HTML。

> ⚠️ 本模组包含成人向内容（18+），仅供成年玩家在本地单机环境中娱乐使用。

> 🧪 **当前为测试版本**：模组规划了多位原创 NPC，目前仅开放第一位——「阿电」。后续角色与配套剧情将陆续加入，功能与数值可能随时调整，存档不保证向前兼容。

---

## 📌 概述

本模组计划引入**多位原创 NPC**，并提供若干生活质量类功能。测试阶段当前仅开放首位 NPC **「阿电」**。阿电的人设基调为**青涩纯情**——容易脸红、结巴、眼神躲闪，主动亲近是「鼓起勇气碰一下」型，做完自己先不好意思。

模组以可插拔方式接入本体：所有注入规则集中在 `boot.json`，不修改本体 passage 原文，卸载即恢复。

## ✨ 主要功能

### 🧑 阿电（测试阶段首位 NPC）

- **社交面板注册**：阿电进入恋爱 NPC 区，含好感 / 信任 / 嫉妒 / 性欲四条属性条，告白成功后占据恋人心形槽位。
- **初识与日常**：午餐相遇剧情、食堂共餐、一起自习、周末集市砍价邀请喝汤。
- **周六夜场打工**：阿电周六傍晚在脱衣舞俱乐部当小调酒师，玩家可去吧台照顾他，或花 £400「点花」进入单独包厢（兔女郎装服务），包间内可持续聊天 / 点酒 / 亲密互动，直至打烊或主动结束。
- **自愿遭遇战**：与阿电成为恋人后，可在房间（20:00 后、性欲 ≥ 40）或周六包厢中主动开启自愿遭遇战，含青涩反应系统（紧张度、主动率、玩家/阿电情动、高潮结算），支持中途喊停。
- **嫉妒暗线**：凯拉尔式嫉妒计量，含跟踪、杀人、囚禁（斯德哥尔摩 / 撬锁逃脱 / 报案 / 硬坏结局进 NG+）多阶段事件。

### � 电脑系统

#### 硬件与组装
- **多地点电脑**：安全屋都可使用电脑。
- **部件商店**：CPU / GPU / 内存 / 硬盘 / 电源 五大类，每类多档可选，价格随性能递增且有周价格波动。
- **组装与拆装**：玩家可购买部件自行组装，也可拆下已有部件出售（二手折价）。
- **性能评分**：综合各部件计算性能分，影响应用能否运行及运行效果。
- **移动电脑**：可将自己的电脑搬到不同地点使用。

#### 应用系统（弹窗桌面）
- **桌面界面**：点击电脑进入弹窗桌面，显示已安装应用图标、当前硬件状态、游戏内时间。
- **应用商店**：桌面内置 🛒 图标，浏览并安装/卸载应用，安装仅占硬盘空间。
- **内存机制**：安装应用只占硬盘，运行时才占内存；后台工具额外占用内存，内存不足无法开启。
- **时间显示**：桌面与各应用顶部均显示 🕐 当前游戏内时间（HH:MM）。

#### 娱乐应用
- **独立小游戏 / 3A大作 / 在线视频 / 音乐播放器**：消耗游戏内时间（每局 1 小时），降低压力，部分提升性欲。
- 3A 大作支持光线追踪、DLSS 等后台工具（纯娱乐，无收益加成）。

#### 接零活赚钱系统
- **接单与干活分离**：
  - 「接零活平台」负责浏览和接单，显示订单的软件类型、难度、报酬、截止天数。
  - 接单后需去**对应工作软件**（视频剪辑 / 图片处理 / 编程 IDE）消耗时间推进进度，达到 100% 才能提交拿钱。
- **订单持久化**：进度存入独立变量，切换软件、退出电脑后不丢失。
- **难度分级**：

| 难度 | 所需时间 | 截止天数 | 报酬倍率 |
|------|---------|---------|---------|
| 小 | 3 小时 | 2 天 | ×1 |
| 中 | 12 小时 | 3 天 | ×2 |
| 大 | 24 小时 | 5 天 | ×4 |

- **报酬计算**：基础 20~200 随机浮动 × 难度倍率 × (1 + 后台工具加成)。
- **超时机制**：订单有截止日期，超时无法提交，可主动放弃。
- **后台工具**：各工作软件及接零活平台可开启 AI 辅助类工具，提升接单收益，但占用内存。

#### 在线学习（浏览器）
- 浏览网课平台学习各科，每次 30 分钟，进度 +2、压力 +10。
- 各科最多学到 **C+**，再高需去学校上课。
- 进度满 200 自动升级成绩等级。

### 🐰 玩家转化系统（暂未开放）

- **兔子转化 / 人鱼转化**：完全独立的玩家系统（与阿电无关），由后续 NPC 剧情的特定行为与事件驱动。
- **三阶段渐进外观**：兔子（兔耳→兔尾→兔腿）、人鱼（鳃→鳞片→鱼尾），转化值 0~100，阈值 30/60/90 升阶。
- **与本体框架兼容**：部件状态存入 `$transformationParts`，本体 `checkTFparts`、隐藏部件创伤机制自动生效；每日 -1 衰减，需持续接触触发源维持。
- **镜子检视页**：任一转化达 1 阶段后，镜子主菜单出现「检视身体的变化」，可查看外观描述并隐藏/显示各部件。

### 🎨 其它

- **作画约稿系统**：手机 APP 内接单 / 练习，技能评级复用本体 `skilllettergrade`
- **贩卖机**：多地点部署，凌晨可砸机
- **作弊菜单页**：注入到本体作弊器「其它」页签，可调整阿电 / 手机 / 电脑 / 绘画 / 小黄书全部数值

## 📦 安装

1. 安装 **TweeReplacer** 插件。
2. 将 `MyFirstMod.zip` 拖入模组管理器，或解压 `MyFirstMod/` 目录到 `mods/` 下。
3. 确保加载顺序在 **Lyra 汉化模组之后**。
4. 打开游戏即可。
