# MyFirstMod · 人物附加与生活质量提升

面向 **Degrees of Lewdity 0.5.10.12 Lyra 汉化版** 的 SugarCube/Twee 模组，基于 [TweeReplacer](https://github.com/.../TweeReplacer) 注入实现，无需改动本体 HTML。

> ⚠️ 本模组包含成人向内容（18+），仅供成年玩家在本地单机环境中娱乐使用。

> 🧪 **当前为测试版本**：模组规划了多位原创 NPC，目前仅开放第一位——「阿电」。后续角色与配套剧情将陆续加入，功能与数值可能随时调整，存档不保证向前兼容。

---

## 📌 概述

本模组计划引入**多位原创 NPC**，并提供若干生活质量类功能。测试阶段当前仅开放首位 NPC **「阿电」**。阿电的人设基调为**青涩纯情**——容易脸红、结巴、眼神躲闪，主动亲近是「鼓起勇气碰一下」型，做完自己先不好意思。

模组以可插拔方式接入本体：所有注入规则集中在 `boot.json`，不修改本体 passage 原文，卸载即恢复。

## ✨ 主要功能

### 🧑 阿电（测试阶段首位 NPC）

- **社交面板注册**：阿电进入恋爱 NPC 区，含好感 / 信任 / 嫉妒 / 性欲四条属性条，告白成功后占据恋人心形槽位。
- **初识与日常**：午餐相遇剧情、食堂共餐、一起自习、周末集市砍价邀请喝汤。
- **周六夜场打工**：阿电周六傍晚在脱衣舞俱乐部当小调酒师，玩家可去吧台照顾他，或花 £400「点花」进入单独包厢（兔女郎装服务），包间内可持续聊天 / 点酒 / 亲密互动，直至打烊或主动结束。
- **自愿遭遇战**：与阿电成为恋人后，可在房间（20:00 后、性欲 ≥ 40）或周六包厢中主动开启自愿遭遇战，含青涩反应系统（紧张度、主动率、玩家/阿电情动、高潮结算），支持中途喊停。
- **嫉妒暗线**：凯拉尔式嫉妒计量，含跟踪、杀人、囚禁（斯德哥尔摩 / 撬锁逃脱 / 报案 / 硬坏结局进 NG+）多阶段事件。

### 📱 手机系统

- 多型号手机 + 耐久 / 修理系统
- **电量系统**：待机耗电、低电关机、咖啡馆 / 学校 / 安全屋可充电
- **战斗互动**：闪光灯消耗电量对全体敌人造成血量上限 5% 伤害；极低概率被抢 / 街头被偷，警察局失物招领
- **上课锁定**：上课期间禁用约稿 / 打车 / 网购 / 相机等耗时 APP
- **打车 DoDo**：真实街道邻接表计算距离与价格，上车过场
- **掏夕夕次日达**：下单次日送达，含防摔手机壳（耐久损耗减半）、充电宝、速写本、数位板、巧克力
- **新联系人**：阿电 / 罗宾 / 惠特尼 / 艾弗里 / 凯拉尔 / 悉尼（哈珀），各自可打电话、发短信话题池
- **小黄书社交平台**：发自拍 / 动态涨粉、打赏变现，联动暴露度与名声

### 🎨 其它

- **作画约稿系统**：手机 APP 内接单 / 练习，技能评级复用本体 `skilllettergrade`
- **贩卖机**：多地点部署，凌晨可砸机
- **作弊菜单页**：注入到本体作弊器「其它」页签，可调整阿电 / 手机 / 绘画 / 小黄书全部数值

### 🗺️ 后续规划（测试中）

- 更多原创 NPC 的相识 / 日常 / 恋爱剧情
- 跨 NPC 的社交网络与冲突事件
- 阿电嫉妒暗线剩余分支的文本补全
- 手机系统更多 APP 与联系人话题

## 📦 安装

1. 安装 **TweeReplacer** 插件。
2. 将 `MyFirstMod.zip` 拖入模组管理器，或解压 `MyFirstMod/` 目录到 `mods/` 下。
3. 确保加载顺序在 **Lyra 汉化模组之后**。
4. 打开游戏即可。
